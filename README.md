# LightPin

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Apple 芯片 macOS 截图工具，常驻菜单栏，不显示 Dock 图标。翻译仅预留接口，不联网。

## DMG 站外发行

[公司签名、公证与 DMG 发布说明](Developer-ID.md)。发布脚本为 `scripts/package-dmg.sh`。

## Mac App Store 版本（0.8.0，构建 28）

用 Xcode 打开 `LightPin.xcodeproj` 并选择 LightPin scheme。当前支持 Apple 芯片和 macOS 14 及以上版本。在 Signing & Capabilities 选择实际公司团队，将 Bundle Identifier 设置为该团队在开发者后台注册、与 App Store Connect 记录一致的标识。Product → Archive 后在 Organizer 运行 Validate App。

商店目标开启 App Sandbox、用户选择文件的读写和 Hardened Runtime。历史保存在容器中的 Application Support，可从控制页打开。隐私政策与隐私清单随应用打包；提交前由发行主体补充有效联系渠道并将政策发布为公开 HTTPS 页面，在 App Store Connect 填写其 URL。仅本地验证可在 xcodebuild archive 时覆盖 CODE_SIGN_IDENTITY=- 和 CODE_SIGN_STYLE=Manual；正式验证使用公司团队签名。

## 自用版安装与更新

退出旧版后双击 `.pkg` 安装包。始终更新 `/Applications/LightPin.app`，不再解压出新副本。误开另一份应用时会唤起已有实例。

签名复用登录钥匙串中的本机证书，未进行 Apple 公证。首次使用或更换签名身份时，可能需要授权屏幕录制。不要删除固定证书或每次重新生成。

## 本次修复

- 选区放大镜增加 3pt 深灰边框和细浅色外沿，在明暗背景上均可辨识。

- 区域标注与遮罩菜单缩小为 140 × 70pt，使用图标、浅绿选中底色、右侧勾选与圆角边缘。

- 空白文本框失焦后自动删除（仅空格或换行也视为空白），已输入文字保留。

- 文本结束编辑后不再添加白色描边，保留所选文字颜色。
- Command + W 关闭当前窗口：支持控制窗口、设置、识别结果及工具选项面板；在截图画布中直接取消本次截图。关闭普通窗口后应用继续常驻菜单栏。保存/打开对话框中等同取消。

## 截图操作

- 菜单栏图标左键打开控制窗口，右键可进入快捷键设置、截图、退出。
- 默认截图快捷键为 Control + Option + 2，控制窗口为 Control + Option + 1；可在设置中更改或禁用。
- 进入截图后自动选择鼠标下的窗口，Tab 向下切换、Shift + Tab 反向切换。完全被其他窗口遮住的窗口不进入候选，部分可见窗口仍可选择。
- 单击确认整窗，或拖动自由框选。整窗只取窗口主体，不扩展阴影，也不还原被遮挡的内容。
- 框选完成后不选中任何标注工具，此时可拖动选区。再次点击已选工具即可恢复拖动状态；不再显示单独的拖动按钮。区域内显示手形指针，拖动时变为抓取指针。
- 拖动改变取景范围，选区限制在当前显示器内。已有标注随选区移动；拖动或调整锚点后变为自由矩形选区。
- 四角与四边共 8 个锚点可调整区域，显示对应方向的缩放指针。框选和调整锚点期间显示像素放大镜。
- 双击选区、Enter 或 Command + C 完成并复制；Command + S 保存 PNG。文字工具内双击仍保留编辑文字的含义。
- 选中标注工具时，Esc 先取消工具选择并恢复拖动选区，保留已有标注、隐藏二级面板；再次 Esc 返回未确认选区状态，最后 Esc 退出。编辑选区时，右键或工具栏返回按钮清除当前选区和标注，回到未确认选区的截图状态；再次右键或 Esc 才退出。工具栏 X 可直接退出，不保存历史。工具栏、边框、尺寸提示不会写入导出图片。

## 编辑工具

工具栏顺序：区域标注、箭头、画笔、遮罩、文字，随后为撤销、重做、返回选区、文字识别、保存、退出、完成。颜色与字号/线宽移至主工具栏下方的二级面板。区域标注右侧展开可选矩形或椭圆；遮罩右侧展开可选色块覆盖或马赛克。主按钮切换工具，展开按钮只负责显示选项。默认线宽为 2pt。

文字工具点击画布后直接输入，按文本框宽度换行；拖动顶部绿色条移动正在编辑的文字，已完成文字可拖动或双击再次编辑。字体与线宽独立设置，颜色使用系统取色盘。Command + Z / Command + Shift + Z 撤销和重做。

箭头拖动期间隐藏指针，结束后恢复。打开本地图片也使用原地编辑界面，但禁用桌面选区拖动。色块覆盖使用当前颜色进行不透明填充；马赛克对框选区域做像素化，宽度选项控制像素块大小，支持撤销与重做。

## 性能与窗口选择

取消进入截图前逐窗读取两张图片的流程。每个显示器只预取桌面图，随后立即展示浮层。鼠标停留 120ms 后才读取当前窗口的圆角轮廓，异步更新并缓存；读取失败暂以 12pt 圆角回退。截图前隐藏窗口的固定等待由 180ms 缩短为 60ms。

可见性按窗口前后顺序减去前景窗口矩形的并集，能排除被多个窗口共同完全遮挡的窗口。透明度不足 1 的前景窗口不用于完全遮挡判定。窗口圆角的细小空隙不单独计入。

整窗阴影扩边、独立含阴影图像及透明阴影导出已移除。桌面快照中本来存在的其他窗口阴影不作修改。

## 数据与权限

文字识别使用本机 Vision；翻译尚未接入服务。完成后的图片保存于应用的 Application Support 目录下的 `LightPin/Captures`，控制窗口显示最近 30 条，历史不自动清理。取消截图不保存。

关闭控制窗口只隐藏界面，退出请使用菜单栏的退出命令或 Command + Q。当前不设置开机启动。

拒绝授权后，可从控制窗口打开系统屏幕录制设置。授权后点击“重新尝试”，或按系统提示重新启动应用。

## 构建与验证

需要 Xcode / Swift，无第三方包依赖。

```sh
python3 scripts/setup-signing.py
scripts/package-app.sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/clang-cache" swift test --disable-sandbox --cache-path "$PWD/.build/cache"
```

首次设置签名后，私钥仅保存于登录钥匙串；身份指纹保存于 `~/Library/Application Support/LightPin/Signing/identity.txt`。构建缺少身份时停止，不回退临时签名。可通过 `LIGHTPIN_SIGNING_IDENTITY` 显式选择其他证书；更换证书可能需要重新授权。

中间应用位于隐藏目录 `.build/app/LightPin.app`，安装包默认位于 `dist/LightPin.pkg`。`scripts/install-local.py` 可在应用已退出时将构建安装到固定位置，覆盖失败会回滚，不修改历史数据。

30 项测试通过，覆盖窗口联合遮挡、部分可见、默认拖动、移动后的裁切像素、双击完成、Retina 导出、透明圆角、快捷键和标注交互。浮动工具栏已完成合成图片渲染检查；真实桌面进入截图的耗时仍受系统截图接口和显示器数量影响。

0.5.0 的工具栏采用近白色底板、深色可用图标、绿色选中背景与悬停反馈；只有实际不可用的撤销/重做按钮置灰。区域、遮罩菜单及马赛克预览已完成渲染检查。

## 0.5.2 二级样式面板

仅在选中标注工具时显示，恢复拖动选区状态、返回或调整区域时隐藏。区域标注、箭头和画笔显示线宽及颜色；文字显示字号及颜色；色块覆盖仅显示颜色；马赛克仅显示强度。提供 2/4/8pt 快捷线宽、精确数值下拉、六种常用色和系统自定义取色盘。

主工具栏和二级面板作为整体布局，靠近屏幕底部时整体移到选区上方，二级面板仍位于主工具栏下方；窄屏可横向滚动。显示与隐藏不改变当前颜色和线宽设置。
