# LightPin

LightPin 是为 Apple 芯片 Mac 开发的菜单栏截图工具。指向窗口后双击，即可复制整窗截图；也可以拖出一块区域，直接在原处画箭头、遮盖信息或提取文字。截取长网页或聊天记录时，选定区域后向下滚动，LightPin 会把连续画面拼成一张长图。

**系统要求**　Apple 芯片（arm64），macOS 14 或更高版本。  
**下载**　[v0.8.0 安装包（DMG）](https://github.com/huangyixu/LightPin/releases/download/v0.8.0/LightPin-0.8.0-28-arm64.dmg) · [发行说明与 SHA-256 校验文件](https://github.com/huangyixu/LightPin/releases/tag/v0.8.0)

## 安装与第一次截图

1. 打开 DMG，将 LightPin 拖入「应用程序」，再从「应用程序」启动。更新时先退出旧版，再替换同名应用。
2. 按 **Control + Option + 2**，或点击菜单栏图标，在控制窗口选择「截图」。
3. 首次截图时，按 macOS 提示为 LightPin 开启屏幕录制权限。若授权后还停在提示页，点击「重新尝试」，或按系统提示退出并重新打开应用。
4. **截整个窗口**时，把指针移到目标窗口，看到边框后直接双击。**截局部**时，按住鼠标拖出矩形，松开后可以编辑，也可以直接双击选区复制。回到聊天框或文档，按 **⌘V** 粘贴。

## 选择窗口与精确框选

| 你想做什么 | 如何操作 |
| --- | --- |
| 截取重叠窗口 | 指向重叠处，按 Tab 从前往后切换候选窗口，Shift + Tab 反向切换。部分露出的窗口可选，完全被遮住的窗口会跳过。截图保留桌面上的实际遮挡关系。 |
| 保留窗口圆角 | 单击智能选中的窗口进入编辑，或双击直接复制。整窗导出时圆角外为透明像素，取景范围止于窗口边缘。 |
| 精确选到某个像素 | 手动框选或拖动边缘锚点时，跟随指针的放大镜会显示附近像素。四角和四边中点共八个锚点，可以分别微调宽、高或两个方向。 |
| 移动或重选 | 未选工具时，在选区内拖动即可移动取景范围。移动或缩放整窗选区后会切换为自由矩形。右键或点击工具栏的返回按钮，可清除本次选区和标注，留在截图状态重新选择。 |

## 在选区中标注

单击智能选中的窗口或松开手动选框后，浮动工具栏会贴近选区显示。选中工具时，下方会出现它能调整的参数；再次点击同一工具即可收起面板，恢复拖动选区。

| 工具 | 用法 |
| --- | --- |
| 区域标注 | 展开形状菜单，在矩形和椭圆之间切换，再拖动圈出重点。默认线宽为 2 pt，可调整线宽和颜色。 |
| 箭头 | 从起点拖向需要指示的位置。拖动期间指针隐藏，方便观察箭头尖端的落点。 |
| 画笔 | 按住鼠标自由绘制，适合手写、划线；二级面板提供线宽、常用色和系统取色盘。 |
| 遮罩 | 选「色块覆盖」后拖出不透明色块；选「马赛克」后拖出像素化区域，可调整像素块大小。 |
| 文字 | 选中文字工具后，在目标位置单击并输入。文字会在选区内换行；拖动文本框顶部的绿色条可移动正在编辑的文字。完成后仍可拖动或双击修改，空白文本框在失焦时自动移除。 |

标注可以撤销和重做。点击「完成」复制成图，或按 **⌘S** 选择位置保存 PNG。控制窗口的「打开图片…」也可以用同一套工具编辑已有的 PNG、JPEG、TIFF 和 HEIC 图片。

## 区域滚动截图

1. 在网页、聊天记录或文档中，框住会随滚动变化的内容。尽量把固定标题栏和侧边栏留在框外。
2. 在添加标注前，点击「区域滚动截图」，然后在原窗口中向下滚动。相邻画面要留出重叠内容，LightPin 会自动比对，只追加新出现的部分。浮动面板会显示已拼接的像素高度。
3. 到达末尾后点击「完成」，即可复制长图。若两次画面无法对齐，可向上回滚少许找回重叠内容，再慢慢向下滚动；也可以选择「完成已拼接部分」，保留已经接好的内容。

## 文字识别、历史与隐私

- **提取文字**　在选区工具栏点击文字识别，LightPin 会使用 Mac 上的 Vision 框架识别图中文字。可以在结果窗口校对、修改，再点「复制文字」。v0.8.0 的在线翻译仅预留开发接口。
- **找回截图**　完成的截图以 PNG 存入本机应用数据目录。控制窗口列出最近 30 张，点击记录可重新编辑。更早的文件仍然保留，可通过「打开文件夹」在 Finder 中查看或删除。取消本次截图不会写入历史。
- **数据处理**　截图、拼接和文字识别都在本机完成。可以从控制窗口查看随应用提供的[隐私政策](Store/Privacy.html)。

## 菜单栏与快捷键

左键点击菜单栏图标打开控制窗口，右键可直接截图、设置快捷键或退出。在控制窗口开启「登录时启动 LightPin」后，下次登录会在菜单栏后台启动，需要配置时再点击图标。

| 操作 | 默认按键 |
| --- | --- |
| 开始截图 / 打开控制窗口 | Control + Option + 2 / Control + Option + 1，可在「快捷键设置…」中更改或禁用 |
| 完成并复制当前选区 | 双击选区、Return 或 ⌘C；编辑文字时保留文本操作 |
| 保存 PNG | ⌘S |
| 撤销 / 重做标注 | ⌘Z / ⇧⌘Z |
| 分层返回 | Esc，依次从已选工具回到拖动状态、清除选区、退出截图 |
| 关闭窗口 / 退出应用 | ⌘W / ⌘Q。关闭控制窗口后，仍可通过全局快捷键截图 |

## 构建与发行

使用完整 Xcode 打开 `LightPin.xcodeproj`，选择 `LightPin` scheme 运行。项目也提供 Swift Package，可在项目根目录执行 `swift test` 运行测试。正式 DMG 的证书配置、归档、公证与 Gatekeeper 验证步骤见 [Developer ID 发行指南](Developer-ID.md)。
